# Datasets

Holds all project data.

- `raw/` — data exactly as received from STADIOEquities. **Never edit these files.**
- `processed/` — cleaned, feature-engineered, model-ready datasets produced by scripts/notebooks.
- `external/` — any supplementary or reference data from outside the client.

> Data files are excluded from version control via `.gitignore`; only this documentation is tracked.
